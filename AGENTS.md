# Repository instructions

This repository starts with an as-is import of the existing 1-ad.com website.
Keep the baseline appearance, copy, behavior, metadata, analytics, and creative
assets unchanged until the owner requests the next round of work.

The deployable website is at the repository root. Preserve existing paths and
creative preview query URLs. The contact endpoint requires PHP and private
server-managed dependencies described in README.md.

Do not commit credentials, private contact messages, or operating-system metadata.
